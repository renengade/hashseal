# 核心概念

## 三件产物

| 文件 | 内容 | 作用 |
| --- | --- | --- |
| `.sig` | JSON：格式版本、算法、摘要、大小、文件名、签名者、签名 | 内容完整性 + 来源 |
| `.tsr` | RFC 3161 `TimeStampResp`（DER） | 签名在何时已存在 |
| `MANIFEST.sha256` | `sha256sum` 格式清单 | 绑定整批文件 |

`.sig` 是自描述 JSON，但**判定只依赖真实文件 + 公钥**。

## 公钥指纹与信任链

```
A 的私钥 ──签名──> 文件 + .sig ──交给 TSA──> .tsr
                        │
B：核对公钥指纹（独立渠道）← 只做一次
                        │
                之后所有文件自动验证
```

⚠️ 公钥指纹必须走与文件不同的信道。从同一个聊天窗口一起收下公钥和 `.sig` 等于没验证。

## 清单为什么存在

逐个签 `.sig` 防不住"删掉文件连同签名"；清单绑定整批文件的完整集合。

## 时间戳为什么盖在 `.sig` 上

`.sig` 已绑定内容；给签名盖时间戳，一份令牌同时证明"内容"和"签名时间"。

## 目录默认布局

```
dist/
├── a.txt
├── b.txt
└── .hashseal/
    ├── MANIFEST.sha256
    ├── MANIFEST.sha256.sig
    └── MANIFEST.sha256.sig.tsr
```

兼容旧版根目录布局。
