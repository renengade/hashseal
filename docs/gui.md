# GUI（本地 Web 界面）

`hashseal gui` 会在 `127.0.0.1` 启动一个零依赖的本地 Web 服务，用浏览器完成与 CLI 完全相同的操作。GUI 与 CLI 共用同一套核心代码、配置文件、密钥和审计日志，两者可以同时使用。

## 启动

```bash
hashseal gui
```

终端会打印形如下面的地址（token 每次启动都不同）：

```
hashseal GUI 已启动（仅本机）
  地址: http://127.0.0.1:53421/#token=xxxxxxxx
```

用浏览器打开该地址即可。Ctrl+C 停止服务。

### 常用选项

| 选项 | 说明 |
| --- | --- |
| `--port N` | 固定端口（默认随机空闲端口） |
| `--no-browser` | 不自动打开浏览器，只打印地址 |
| `--root PATH` | 允许访问的根目录，可多次指定 |
| `--read-only` | 只读模式：禁用签名/生成/解包等写操作 |
| `--idle-timeout MIN` | 闲置自动退出分钟数（默认 30，0 = 不退出） |
| `--vault-timeout MIN` | 口令闲置自动锁定分钟数（默认 0 = 记住直到退出） |

默认根目录是**用户主目录 + 当前目录**；其他路径用 `--root` 添加。例如 WSL 里要访问 Windows 文件：

```bash
hashseal gui --root /mnt/c/Users/你的用户名
```

## 页面

按一次真实使用的工作流顺序排布：**密钥 → 签名 → 验证 → 时间戳与证明 → 目录与分发 → 工具 → 审计 → 设置**。

| 页面 | 工作流位置 | 功能 |
| --- | --- | --- |
| 概览 | 入口 | 快捷入口、最近操作、审计摘要、安全提示 |
| 密钥 | 第一步 | 生成密钥对、核对公钥指纹、口令保管 |
| 签名 | 第二步 | 签名文件/目录，可选 RFC 3161 时间戳 |
| 验证 | 第三步 | 验证签名 / 快速检查（不联网） |
| 时间戳与证明 | 增强 | 续期时间戳、in-toto 证明生成与验证 |
| 目录与分发 | 分发 | 生成清单、对比、打包/解包 bundle、SBOM |
| 工具 | 辅助 | 计算 SHA-256、查看 `.sig`/`.tsr` 元数据、OpenTimestamps |
| 审计 | 回溯 | 查看/筛选审计日志（GUI 操作标记 `source=gui`） |
| 设置 | 维护 | 配置展示、生成配置模板、退出服务 |

文件选择使用**服务端目录浏览**（不做浏览器上传），因此任意大小的文件都不会经过浏览器；浏览器拖拽拿不到本地路径，这是浏览器安全模型决定的，请使用“浏览…”按钮或直接粘贴路径。

## 口令保管

- 加密私钥的口令只保存在 GUI **进程内存**中，绝不写盘、不进日志；
- 解锁一次后，签名/时间戳/证明操作会自动取用；
- 侧栏“全部锁定”立即清除；退出进程自动清空；
- 默认记住直到退出；可用 `--vault-timeout 15` 让闲置 15 分钟自动锁定。

## 安全模型

- 服务只绑定 `127.0.0.1`，每次启动生成 32 字节随机 token；
- 地址中 `#token=…` 是唯一凭证：不要分享地址、不要截图泄露；
- 所有请求校验 Host / Origin / token，防 DNS rebinding 与跨站调用；
- 所有文件路径必须在 `--root` 声明的根目录内；
- 危险选项（`--allow-unverified-chain`、`unpack --no-verify` 等）在界面中标红并需要二次确认；
- 私钥内容永远不进入浏览器，浏览器只传输路径和口令。

### 信任边界

GUI 防的是“**非本机来源**”和“**跨站网页**”，不防同权限的本机程序：

- 能读到终端地址或进程内存的本机恶意程序，与能直接读你私钥文件的程序是同一威胁等级，超出 GUI 的防御范围；
- 有权访问 `127.0.0.1` 页面的浏览器扩展同样可以充当用户，建议高价值密钥使用专用浏览器配置或直接用 CLI。

## 与 CLI 的关系

| 场景 | 建议 |
| --- | --- |
| 日常交互式操作 | GUI |
| 脚本、CI、批量任务 | CLI |
| 极高价值密钥的签发 | CLI（减少浏览器暴露面） |

GUI 的每次操作都会在审计日志中标记 `source=gui`，与 CLI 的 `source=cli` 区分。等价 CLI 命令可在结果卡片中一键复制，方便复现与过渡到命令行。

## 常见问题

**浏览器打不开地址？**
WSL2 中可先确认 Windows 能访问 WSL 的 127.0.0.1 端口；若不行，在 WSL 内安装 Firefox/Chromium，或用 `--no-browser` 手动复制地址。

**401 会话无效？**
服务重启后 token 会变化。回到终端复制新地址重新打开。

**路径提示“不在允许的根目录内”？**
用 `hashseal gui --root <目录>` 把该目录加入白名单。

**端口被占用？**
默认随机端口不会冲突；若用 `--port` 固定端口，换一个即可。
