# GUI 界面

`hashseal web`（`hashseal gui` 为兼容别名）在 `127.0.0.1` 启动一个零依赖的本地 Web 服务，
用浏览器完成与 CLI 相同的操作。GUI 与 CLI 共用同一套核心代码、密钥、配置与审计日志，两者可以同时使用。

> 平台策略：**Windows 是主要目标与主验证平台**，但代码保持跨平台——
> Linux / macOS 使用同一套 GUI，不做平台限制；Windows 专属问题（路径、换行、
> OpenSSL、浏览器打开）有独立测试与文档。

## 启动

```bash
hashseal web
```

终端打印地址（token 每次启动都不同）：

```
hashseal GUI 已启动（仅本机）
  地址: http://127.0.0.1:53421/#token=xxxxxxxx
```

打开即可；Ctrl+C 停止。`--no-browser` 只打印地址，适合 WSL/远程/无桌面环境。

### 常用选项

| 选项 | 说明 |
| --- | --- |
| `--port N` | 固定端口（默认随机空闲端口） |
| `--no-browser` | 不自动打开浏览器 |
| `--root PATH` | 允许访问的根目录（可多次） |
| `--read-only` | 只读模式：服务端禁用写操作 |
| `--idle-timeout MIN` | 闲置自动退出分钟数（默认 30，0 = 不退出） |
| `--vault-timeout MIN` | 口令闲置锁定分钟数（默认 0 = 记住到退出） |

文件浏览默认放开**整个文件系统**：WSL/Linux 可浏览 `/`（含 `/mnt/*`），
Windows 会列出所有存在的盘符（`C:\`、`D:\` …）；主目录与当前目录作为默认快捷位置。
如需收紧为白名单，用 `--restrict-roots`（此时仅主目录/当前目录/`--root` 可访问）。

```bash
hashseal web --restrict-roots --root /data     # 仅在明确需要时收紧
```

### 升级

GUI 由**你启动的那一份 hashseal** 提供，没有独立安装包。升级方式：

```bash
# WSL/Linux/macOS
curl -fsSL .../install.sh | sh
# Windows
irm .../install.ps1 | iex
```

WSL 与 Windows 是两套独立安装，需分别升级（`hashseal --version` 核对）。
升级后浏览器 F5 即可（静态资源 `no-store`，无需清缓存）。

## 页面（按工作流）

| 页面 | 功能 |
| --- | --- |
| 概览 | 本地优先/开放格式/可信时间特性、三步引导、最近操作、审计摘要、安全提示 |
| 密钥 | 生成密钥对、公钥指纹、口令保管状态 |
| 签名 | 签名文件/目录，默认勾选可信时间戳（无 OpenSSL 时默认关闭并提示） |
| 验证 | 验证签名 / 快速检查（不联网） |
| 时间戳 | 申请/续期时间戳、in-toto 证明生成与验证 |
| 分发 | 清单、对比、bundle 打包/解包、SBOM |
| 工具 | SHA-256、查看 `.sig`/`.tsr` 元数据、OpenTimestamps |
| 审计 | 查看/筛选审计（GUI 记录 `source=gui`） |
| 设置 | 配置展示、生成 TOML 模板、退出服务 |

## 表单行为

- **最小露出面**：默认只显示必需项；常用可选项（署名、输出路径、时间戳开关）
  横排两列；TSA 地址/信任根/超时/重试/排除/并行等在折叠的「高级选项」里；
- **路径默认预填**：私钥/公钥按配置或启动目录的 `hashseal_private.pem` /
  `hashseal_public.pem` 预填；清单/SBOM/证明输出也有默认值。越出根目录的默认不预填；
- **切换菜单不丢输入**：表单内容在内存中保留（刷新页面清空）；
  **口令不缓存**，避免“眼睛”回看；
- **路径选择器**：服务端目录浏览（不是上传），支持根目录与「主目录/桌面/下载/文档」
  快捷入口（仅限 `--root` 内）、面包屑（Windows 盘符/UNC 正确分级）、过滤、隐藏文件、多选；
  选定后只有「确定 / 取消」；
- **输出路径建议**：bundle 选择目录后自动填入 `<目录>.zip`；unpack 选择 zip 后填入同级
  `<名字>/`（手动改过则不再覆盖）；
- **复制与查看**：路径/口令输入框内嵌复制按钮；口令框另有眼睛按钮切换明文；
- **时间戳与 OpenSSL**：检测到系统无 openssl 时，签名表单默认不勾选时间戳，
  签名/时间戳页顶部常驻提示；签名成功但时间戳失败时显示「签名已生成，时间戳未完成」并引导续期；
- **口令规则**：生成密钥对时要求 ≥8 位且包含大小写字母/数字/特殊字符中至少 3 种
  （规则显示在输入框 placeholder，输入不合规红边，提交被拦截）；
  已有密钥时隐藏口令输入，勾选「覆盖已有密钥」后才显示；
- **私钥状态**：选择私钥后显示「已加密·口令已记住 / 已加密·需要口令 / 未加密 / 不存在」；
- **危险选项**（跳过链校验、跳过解包校验、信任内置公钥）标红并二次确认；
- **结果**：结构化展示（不提供 CLI 原始输出），含失败原因、未列入清单、时间戳详情；
  渲染异常会显示带堆栈的红色错误卡，不会静默空白；
- **审计页**：`command_failed` 等无 `ok` 字段的事件会以 ❌ 标记并显示错误摘要。

## 口令保管

- 加密私钥的口令只保存在 GUI **进程内存**，绝不写盘、不进日志/审计；
- 签名/生成密钥表单默认勾选「记住口令直到退出」，成功一次后自动取用；
- 侧栏底部芯片仅在记住 ≥1 个口令时出现，显示数量，点击 → 确认 → 全部锁定；
- 退出程序自动清空；`--vault-timeout 15` 可闲置自动锁定；
- 口令错误不会保存，并自动丢弃该密钥的旧口令。

## 深链

需要在支持/排查时直达某页，可在 token 后加 `next`：

```
http://127.0.0.1:53421/#token=XXXX&next=%2Fkeys
```

`next` 取页面路由（`/keys`、`/sign`、`/audit` 等）。

## 安全模型

- 只绑定 `127.0.0.1`，每次启动 32 字节随机 token（URL fragment 携带，不进服务器日志）；
- 所有 API 校验 Host / Origin / `Sec-Fetch-Site`，防 DNS rebinding 与跨站调用；
- 严格 CSP，无外链/无内联脚本；静态资源白名单；
- 默认允许访问整机文件（本地 token 保护）；`--restrict-roots` 时仅允许 roots 内，符号链接同样受限；
- 不做浏览器上传，私钥内容永不进入浏览器；
- 只读模式在服务端拦截写操作，不依赖前端隐藏按钮；
- 闲置自动退出（默认 30 分钟）。

### 信任边界

GUI 防「非本机来源」和「跨站网页」，**不防同权限的本机程序**：

- 能读取终端地址/进程内存的本机恶意程序，与能直接读私钥文件的程序等级相同；
- 有权访问 `127.0.0.1` 页面的浏览器扩展可充当用户；高价值密钥建议专用浏览器配置或 CLI。

## 常见问题

**浏览器打不开地址？** WSL2 一般可直接访问 WSL 的 `127.0.0.1`；若不行，在 WSL 内装浏览器，
或 `--no-browser` 手动复制地址。Windows 原生安装会自动打开默认浏览器。

**401 会话无效？** 服务重启后 token 变化，回终端复制新地址。

**提示路径不在根目录？** 启动时加 `--root <目录>`。

**时间戳失败，提示未安装 openssl？** 见 [安装 · Windows 与 TSA 证书链](install.md)。

**attestation.json 是什么？** 供应链证明附件，默认写到启动目录；不参与日常验证，
可删除或在高级选项改输出路径。详见 [证明与 SBOM](attest.md)。
