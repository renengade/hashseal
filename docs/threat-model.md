# 威胁模型

## 资产

- 交付文件的内容与文件名；
- Ed25519 私钥与加密口令；
- `.sig`、`.tsr`、`MANIFEST.sha256`；
- 公钥指纹（信任锚）；
- 审计日志（操作留痕）。

## 信任边界

```
私钥（A 独占）
   │ 签名
   ▼
文件 + .sig ──► TSA ──► .tsr
   │
   ▼
B：核对公钥指纹（独立渠道）→ verify
```

- **A 的私钥**：唯一能产生有效签名的东西；
- **公钥指纹**：B 必须通过独立渠道获得，否则中间人可同时替换公钥与签名；
- **TSA**：只证明「某时刻已存在」，不证明内容正确；其根证书是独立信任锚。

## 主要威胁与缓解

| 威胁 | 缓解 |
| --- | --- |
| 传输中被替换文件 | SHA-256 + Ed25519 签名 |
| 文件和哈希一起被替换 | 签名由私钥产生，攻击者无法伪造 |
| 目录中新增/删除文件 | 清单绑定完整集合，`verify DIR` 检测未列入与缺失 |
| 清单路径逃逸（`../`、绝对路径） | 解析时拒绝，解析后校验仍在根目录内 |
| 符号链接指向目录外 | `verify_tree` 解析真实路径，逃出根目录判失败/跳过 |
| 改名冒充 | 文件名纳入签名，默认拒绝改名；`--name` 显式放行 |
| 私钥泄露 | 口令加密（PBKDF2 60 万次）、0600；轮换/吊销仍待实现 |
| 弱口令 | GUI 强制 ≥8 位 + 3 类字符；CLI 仅警告 |
| TSA 不可信/被攻破 | 多 TSA、指定 `--tsa-ca`、离线验证；单一 TSA 是残余风险 |
| TSA 证书过期 | 按 `genTime` 验证；长期归档需 LTV（未完全实现） |
| 无 openssl 时误判 | 严格模式 fail-closed；非严格模式明确标记「链未校验」 |
| bundle 路径穿越 / zip-slip | 解包拒绝 `..`、绝对路径、符号链接条目 |
| zip bomb | 条目数 ≤10 万、解压后 ≤8 GiB，超限拒绝 |
| 安装脚本被替换 | HTTPS + Release 资产 + `HASHSEAL_SHA256`；构建有 SLSA provenance |
| 供应链依赖被替换 | `uv.lock` 锁定；SBOM 记录组件；in-toto/DSSE 证明 |
| 审计日志被本地篡改 | 本地文件可被同用户改动；无哈希链/外部锚点，合规场景应转发 SIEM |
| 命令失败无审计 | 统一 `command_failed`（CLI/GUI），命令自身失败不重复 |

## 本地 Web GUI

| 威胁 | 缓解 |
| --- | --- |
| 本机其他进程/网页访问端口 | 仅绑定 `127.0.0.1` + 32 字节随机 token（URL fragment） |
| DNS rebinding | 校验 Host 必须为 `127.0.0.1:<port>` / `localhost:<port>` |
| CSRF | JSON Content-Type + 自定义 token 头 + Origin/Sec-Fetch-Site 校验，无 CORS |
| XSS | 严格 CSP、无内联脚本/样式、用户数据只用 textContent |
| 路径穿越 | `--root` 白名单 + `resolve()` 后校验，拒绝越界符号链接 |
| 误操作 | 危险选项标红 + 二次确认；默认拒绝覆盖 |
| 只读绕过 | 服务端按命令白名单拦截写操作 |
| 口令泄露 | 仅进程内存；不写盘/日志/审计；可一键锁定、闲置锁定 |
| 浏览器扩展 / 同用户恶意程序 | **不在防御范围**：可读页面/内存/私钥文件，建议专用浏览器配置或 CLI |
| 回环流量窃听 | 未加密；需本机抓包权限，视为同用户威胁 |

## 残余风险

- 签名者本人签了恶意内容：签名只证明「谁签的」；
- 私钥所在主机被完全控制；
- 本地审计日志不具备防 root 篡改能力；
- 单一 TSA 的可用性与可信度；
- 当前 SBOM 只到文件/依赖组件级，不含完整依赖树与许可证；
- 浏览器扩展或同权限程序可绕过 GUI 的“人工确认”。

## 不在范围内

- 运行环境一致性（Python 版本、依赖行为）；
- 恶意软件检测；
- 私钥托管与硬件令牌（规划中）；
- 多用户/远程访问 GUI。
